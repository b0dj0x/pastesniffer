## What is PasteSniffer?

Dark web paste site scraper for leaked emails, combos, and keys

## Features

- 16 paste site scrapers
- Dark web paste search (Ahmia, OnionLand, Darknet Live via Tor)
- 32 leak detection patterns (emails, combos, API keys, private keys, credit cards, etc.)
- Breach API checks (XposedOrNot, Hudson Rock, EmailRep.io, HIBP)
- Local file/URL scanning
- OSINT link generator (25+ links)
- JSON + combo file export
- Threaded fetching
- Zero config, no API keys needed

## Installation

```bash
git clone https://github.com/b0dj0x/PasteSniffer.git
cd PasteSniffer
pip install -r requirements.txt
```

## Usage

```bash
python3 pastesniffer.py sniff keyword
python3 pastesniffer.py breach user@email.com
python3 pastesniffer.py password mypassword
python3 pastesniffer.py file data.txt
python3 pastesniffer.py url http://example.com
python3 pastesniffer.py osint user@email.com
```
